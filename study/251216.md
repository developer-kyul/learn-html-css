## popover

- popover 기능은 정보전달의 효율성과 유연성을 높이는데 사용
- popover을 할 요소와 작동시킬 요소를 연결해 주어야함

- html

1. popover을 할 요소에 popover속성과 id값을 줍니다.
2. popover을 작동시킬 요소애 popovertarget = "id값"을 지정해서 연결

- css

1. inset: unset 기존 요소의 스타일을 모두 지우기
2. inset-inline: anchor(left); 가로기준으로 배치를 해주기
3. inset-block-start: calc(anchor(bottom) + 4px); 세로요소기준 배치
   clac를 통해 세부적으로 조절도 가능
4. [중요] popover은 기본 세팅이 display none이기 떄문에
   작동시키고 다시 안보이게 작성하려면 아래 속성 사용

```
&:popover-open {
display: flex;
flex-flow: nowrap row;
}
```

## 컨테이너 쿼리

- 뷰포트가 아니라 “부모 컨테이너의 크기”에 따라 컴포넌트 스타일을 바꾸는 CSS 기능

- 사용법이 미디어 쿼리랑 비슷

```
container-type: inline-size;
container-name: post;

container: post / inline-size; 축약형
```

- 해당요소를 컨테이너로 선언하는 것
- inline-size = 가로 크기 기준 보통 이걸 사용  
  -> 한글은 좌에서 우로 작성되서 size는 잘 사용 안 함
- container-name: post;  
   특정 컨테이너에 이름 붙이기

  ```
  @container post (width >= 500px) {
  / 스타일 /
  }
  ```

## @layer

- CSS의 “적용 우선순위”를 사람이 직접 설계하는 기능
- 유지보수성, 독립적 스타일 작성, 스타일 우선순위 부여 등의 이유로 사용
- 전통적인 CSS 캐스케이딩 규칙

1.  !important  
    <em>[NEW] @layer 순서</em>
2.  specificity (id > class > tag)
3.  작성 순서 (나중에 쓴 게 이김)
