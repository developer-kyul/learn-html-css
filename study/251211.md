## [16] 그리드

- Grid Line은 그리드에서 5개의 행을 가질때 6개의 행열이 필요하다.
- Grid Track은 그리드 라인 사이 연속된 공간을 말한다.
- Grid Cell은 그리드 라인이 모여 그려지는 가장 작은 단위(유닛)이다.
- Grid Area는 그리드 라인이 모여 그려지는 공간으로 셀이 묶인 영역을 말한다.
- Grid Gutters 는 행 또는 열 사이 간격(Gap)이다.

- 거터의 최적화,컬럼 최적화 크기 확인 가능 웹사이트(고정형으로 배치할때 download grid for 로 보면 좋음)
  http://gridcalculator.dk/

- 그리드 템플릿에는 행, 열, 영역 이름 설정을 속기형으로 설정 가능

```
grid-template-rows: repeat(5, 50px);
grid-template-columns: repeat(5, 100px);

grid-template: repeat(5, 50px) / repeat(5, 100px) auto;
```

- 그리드 아이템 배치 (라인기반, 영역기반, 이름기반)

```
grid-row-start: 4;
grid-column-start: 4;
grid-row-end: 5;
grid-column-end: 5;

라인 배치 속기법
grid-row: 3 / 5;
grid-column: 2 / 4;

영역 기반 속기법사용
grid-area: 2 / 4 / 4 / 6;
입력순서는 row-start, column-s, row-end, column-e
```

- 암시적 그리드 아이템:  
  명시적으로 배치하지 않은 영역을 채우기 위해 컨테이너가 자동으로 생성하는 트랙에 놓이는 아이템

- 이름 기반  
  이름기반으로 배치하는 것은 area 영역속성을 사용해서 각 요소에 이름을 설정하고, sreas 속성을 사용해서 배치합니다.

```
grid-template-areas:
'euid1 euid1 euid2 euid2 euid3'
'euid1 euid1 euid2 euid2 euid3'
'euid1 euid1 euid2 euid2 euid3'
'euid4 euid4 euid5 euid5 euid5'
'euid6 euid6 euid6 euid7 euid7';

.euid1 {
grid-area: euid1;
}
.euid2 {
grid-area: euid2;
}

```

- fr단위

```
fr단위 예시: 1fr 1fr = 1/2 1/2
grid-area: repeat(4, 25%) 를 (4, 1fr) 로 사용가능-컬럼갯수4개를 각1/4로 배치
```

- 정렬

```
/* align-content: center; y축 중앙정렬
justify-content: center; x축 중앙정렬*/
place-content: center; / 위에 두개의 속기법, 순서는 align,justify /
```

- 아이템 정렬

```
/* justify-items: center; 아이템 블록이 셀안에서 가운데로 이동함
align-items: center; */
place-items: center; / 아이템을 가운데로 /
```

- 개별 아이템 정렬

```
/* justify-self: end;
align-self: end; */
place-self: end; / 위에 두개의 속기법
```

- 함수

```
함수
minmax() 함수-크기값-최소값 최대값을 설정
grid-template-columns: minmax(30px, auto) ->30px은 최솟값, auto 는 최대값

repeat()함수-반복되는 값을 손쉽게 설정
grid-template-columns: repeat(5, 100px); ->5는 반복횟수, 100px은 배열값

repeat에서 컬럼갯수를 줄때, auto-fill / fit 줄 수 있다.
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
컬럼갯수를 auto-fill 로 설정, 컬럼이 최소크기따라서 한열에 보이는 컬럼 갯수 달라짐, fill은 뒤에 공백 남음(+여분의 컬럼이 들어갈 여백공간을 그대로 확보),
auto-fit은 부모요소에 fitting되서, 남은 공백 없음
```

## [17] 다단

- 텍스트로만 이뤄진 인쇄물에서 자주 사용되는 다단(Multi Column) 구조를 구현하기 위한 속성

- column–width  
  column-width는 다단 구성 시 단의 너비를 지정하는 속성,기본 값은 auto(단의 너비를 자동으로 계산)
  단의 너비를 길이값으로 지정하면 단의 갯수는 요소의 너비에 따라 자동으로 계산된다. 여기서 지정된 값은 정확한 길이 값이 아니라 상위 요소가 단을 구성하는 최소 기준 값이 된다.

- column-count  
  column-count는 다단 구성 시 단의 개수를 지정하는 속성, 속성 값에는 단위가 없는 0이 아닌 정수 값으로 단의 개수를 지정, 단의 너비는 자동으로 계산되며, 요소의 너비(예시-웹사이트크기)가 증가해도 갯수유지, 너비만 넓어진다.
