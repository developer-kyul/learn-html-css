변수 안에 변수로 사용하는 방법

- display: contents
  속성이 부여된 요소의 자식이 자신의 부모를 무시하고 조부모의 직계 자손인 것 처럼 동작

- 집 꾸미기라고 생각해보자
  block = 침대 (한 줄 다 차지)
  inline = 책 (작게 옆으로 놓임)
  inline-block = 작은 서랍장 (옆에 놓이지만 크기 조절 됨)
  flex = 정리 도우미 (자동으로 정렬해줌)
  grid = 서랍 칸 6개 있는 책상 (칸이 정해져 있음)
  none = 치워버리기
  contents = 박스는 치우고 안에 든 물건만 남기기
  - svg 에서 viewbox, fill 의 역할이 무엇인지 찾아봤는데요

viewBox : SVG 내부의 좌표 시스템을 정의하여 실제 크기가 어떻든 내부에서 설정한 비율로 그린다.

( SVG 파일의 가로세로 크기(width, height)를 바꿔도, 내부 그림은 이 viewBox 비율을 유지하며 \*\*깨지지 않고 늘어나거나 줄어든다)

fill : SVG 내부의 도형(path, rect, circle 등)에 어떤 색을 칠할지 결정하는 속성이다.

→ html 안에 svg 코드를 넣어서 CSS 로 스타일을 강제로 바꿀수 있어서 유용하다.

## 3. [15] 15-stacking-context

- z-index

  z-index : auto

요소들이 화면에서 누구 더 앞에(위에) 나올지 순서를 결정하는 "우선순위 번호”

숫자가 클수록 위로: z-index: 10은 z-index: 1보다 위에 나타납니다.

음수 사용 가능: z-index: -1을 주면 부모 요소보다 뒤로 숨길 수도 있습니다.

기본값: 설정하지 않으면 보통 auto 또는 0입니다.
