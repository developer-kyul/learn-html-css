## [22]다크모드

### 사용법

1. 한 파일 안에 설정하는 법

```
body {
  background: yellow;
  color: green;
}

/* 다크 모드 스타일 */
@media (prefers-color-scheme: dark){
  body{
    background: #000;
    color: #fff;
  }
```

2. 파일을 개별로 분리해서 사용하는 법

- 접근성 및 효율 측면에서 추천하는 방법은 아님

```
    <link rel="stylesheet" href="/src/css/styles/22-light.css" media="(prefers-color-scheme: light)" />
    <link rel="stylesheet" href="/src/css/styles/22-dark.css" media="(prefers-color-scheme: dark)" />
```

3. 함수 사용

```
/* 함수 사용 */
:root {
  color-scheme: light dark;
}
body {
  color: light-dark(#333b3c, #efefec);
  background-color: light-dark(#efedea, #223a2c);
}

```

4. 파비콘 색상

- 다크모드 사용시에 파비콘 변경하는 법 / head 안에서 변경

```
    <link rel="icon" href="/favicon/sun-cloud.svg" media="(prefers-color-scheme: light)" />
    <link rel="icon" href="/favicon/moon.svg" media="(prefers-color-scheme: dark)" />
```

- SVG 안에서 변경 / svg 코드 안에 style 넣기

```
  <style>
    g{
      fill: #000;

      @media (prefers-color-scheme: dark) {
        fill: #fff;
      }
    }
  </style>
```

## CSS 속성

- inline-size: clamp(최솟값, 기본값, 최댓값);

```
.input {
  input {
    &:has(:user-invalid) .error-message {
      visibility: visible;
    }
    inline-size: 100%;
    min-inline-size: 0;
    block-size: 48px;
    border: 1px solid var(--gray-200);
    /* 커서가 너무 붙어있으면 답답한 느낌을 줄 수 있어서 여백을 줌 */
    padding-inline-start: 0.5em;

    /* &:read-only {
      background-color: var(--gray-100);
    } */

    &:user-invalid + .error-message {
      /* 공간은 차지하고 안보이게 지정하는 속성 */
      /* display none은 공간도 다 안보이게 함 */
      visibility: visible;
    }
  }
}

```

## reflow랑 repaint

- Reflow  
  -> 레이아웃이 달라지는 변화  
  -> 성능 부담이 큼

- Repaint  
  -> 보여지는 방식만 달라지는 변화  
  -> 훨씬 가벼움
