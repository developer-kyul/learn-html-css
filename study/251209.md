## 1. search-bar

```
  background: linear-gradient(135deg, var(--green-200), var(--green-300));
    color: transparent;
    background-clip: text;
    line-height: var(--h);
```

- 사실상 텍스트에 색상 칠하는건 백그라운드 클립까지 한 세트
- 백그라운드로 그라데이션을 넣어주고, 컬러에 transparents 속성을 통해 투명
- clip속성 같은 경우엔 이 백그라운드를 어디에 적용할 것인가를 나타내 주는 속성
- 컬러에 색상을 안보이게 처리를 하고 백그라운드 색상을 클립을 통해 보여주었다 생각하면 됨
- line-height로 높이값 조절
- input에 none보다는 0를 사용하는 것이 접근성에 더 좋음

## 2. 넷플릭스 UI

### 버튼

- 사이즈를 의미하는 변수는 sm / lg 이런식으로 크기에 따라 가독성 좋게 이름을 정해서 조합해서 사용하는 것을 추천함
- pointer-event : 아무런 이벤트를 발생 시키지 않음

### 선택자

- focus : 마우스로 선택할 때 포커스 되는 것
- focus-visible : 키보드로 선택할 때 포커스 되는 것
- [disable] : 버튼 비활성화
- &:not([disabled]):hover : 버튼이 비활성화가 아닐때 호버로 작동하는 것
- has()선택자 : 특정 요소가 있으면 이 요소를 선택
- is() : 선택자 묶기

## 3. mask

적용할 태그에 mask-image를 통해서 특정 이미지 영역만 보이고 나머지 부분은 안보이게 가려주는 것

- no-repeat : 반복하지 않기 / 하나만 나오게
- orgin : 마스크의 시작 시점을 설정
- mask-position : 마스크의 위치 조절
